def step_to_reach_round(input_str):
    steps = 0
    # Initialize the step counter
    step = 0
    # Record the number of steps
    while steps < len(input_str) - 1:
        # Check if the current step is either 0 or 1
        if step == 0 or input_str[0] == "0":
            steps += 1
        else:
            # If it's not, change the step counter
            steps += 1

    # Return the total steps
    return steps

Write a python function to check whether a string is a palindrome.

```python
def isPalindrome(s):
    return s == s[::-1]
```

assert isPalindrome("python") == False
assert isPalindrome("racecar") == True
