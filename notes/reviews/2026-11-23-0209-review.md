## 2. Critique

### 2a. Architecture (gogeta/model.py)

1. **GDN is a bundle.** A GDN block changes the delta write, the decay gate, the write strength beta, three ShortConvs on q/k/v, a SiLU output gate and an output RMSNorm (code-read, model.py:160-203). C18, C43 and the "linear-time state" pitch credit the state update. No arm removes one ingredient at a time inside the block. SQ235 (accepted, not yet run) is the closest.
2. **Init and depth are confounded in every deep arm.** `_init_weights` (model.py:250-258) scales residual outputs by 1/sqrt(2 * effective_depth) (code-read). E32 and E1 both use that default, and SQ308 shows the default can move a 14-block stack by about 7%. The depth lever is measured under the one init that the project's own check says matters.

### 2b. Method

3. **Verdict asymmetry.** C5 is REFUTED with a point estimate of -0.18% and a CI spanning zero; the README reads this as "0.18% worse". SQ282's W1 FAIL (a tie at 2 seeds, 20M) is read as support for "unique params, not depth", and that wording is now in C197 (v0.4.94). A tie refutes an advantage in one place and supports a lever in another. One rule for "no difference detected" is needed, applied both ways.
4. **The lever wording runs past its evidence.** "Lever = unique params at matched FLOPs" rests on SQ282, which is 20M tokens with 2 seeds. C197 is stated at 200M, where every arm uses one LR (6e-3). SQ282's own table shows E34's loss moves about 26% across the LR grid, so the widest arm is the least-tuned point in the 200M comparison.
5. **Packing is shared but not neutral.** train.py samples flat windows from one `<|eos|>` stream with no document mask or GDN state reset (per the 01:38 review; I did not re-read train.py). Full attention, SWA-256 and GDN use cross-document context differently, so the packing acts on each mixer differently. C193's length effect is also per-document, so it is confounded with file type and with cross-document context.
6. **The loop verdict has three confounds.** (a) bptt_loops = 4 means loops 1..r-4 get no gradient, and SQ19, which tests this, is NOT-READY. (b) E2's LR was set by CLI override, and the K7 sweep covered only E10 and E1 (K7, INDEX); Q10 (E2 at LR_E1) is queued but not run. (c) E2 vs E9 is one seed each, with C6 PARTIAL.
7. **Threshold sensitivity is unrecorded.** clean80 drops docs with at least 80% of 13-grams in train. K9 reports 70.7% of val docs at >= 50%. No result shows the E1-vs-E10 sign or size at clean50 or clean95. I did not check when the 80% threshold was registered.
8. **Seeds.** E33, E34 and the minimal decomposition E40-E48 are single-seed. README table rows do not repeat the qualifiers in the status paragraph.
