# K3: associative recall (MQAR), GDN vs plain linear attention

## Question and prediction
- **Question:** does Gated DeltaNet recall key–value pairs better than plain causal linear attention?
- **Prediction (committed before running):** `experiments/checks/PREDICTIONS.md`, section "K3", commit `f1b4ebd`. attn ≥ 95%, gdn 60–95%, linear attention 10–40%, swa(32) < 5%.
- **Pass criteria:** the check is valid only if attn ≥ 90% and swa(32) ≤ 30%. C16 is VERIFIED (vs plain linear attention) if mean gdn ≥ mean linattn + 10 points.

## How to run it
- `wsl -d Ubuntu-24.04 -- bash -c "cd /mnt/c/Users/mreca/Desktop/Gogeta-0 && ~/.venvs/gogeta/bin/python experiments/checks/k3_mqar_recall.py"` (env `K3_STEPS` overrides the steps for smoke tests)
- GPU, about 8.3 min (497 s). Script uncommitted at run time, HEAD `4a3e361`.

## Runs
2 blocks, d=128, 2 heads, MLP 256, vocab 512 (keys 0–255, values 256–511). 64 pairs, then 64 shuffled queries, T=256. Loss and accuracy are taken only at the query-key positions (predicting the next value). 4000 steps, batch 64, AdamW lr 1e-3, warm-up 200, cosine. Eval on 20 fresh batches of 64.

## Results
- **Validity:** FAILED (attn 8.6% < 90%). The check is **inconclusive** and must be redesigned.
- **C16:** not tested. For the record only, gdn − linattn = −1.6 points.

## How to reuse this
- `mqar_batch()` generates MQAR on the GPU and is reusable as is.
- `LinearAttention` is a drop-in mixer, swapped in via `block.mixer`. Its parallel (masked) form is checked against the cumsum form (max |diff| 1.2e-6) at startup.
- **Don't** reuse the training recipe. Even full attention did not learn the task in 4000 steps.

## Caveats
- Deviation: linear attention was trained in the masked parallel form, (φ(q)φ(k)ᵀ ⊙ causal)·v / normaliser, instead of the cumsum form. The two compute the same function (max |diff| 1.2e-6 on random inputs). The cumsum form was about 7× slower and would have exceeded the 15-min budget.
- Redesign ideas (not tested): fewer pairs (e.g. 16–32), more steps or a higher LR, scoring all value positions, or a curriculum. Loss was still falling for attn at 4000 steps (4.29 at step 3000).
- gdn seed 1 stayed near its initial loss (5.52), so it may not have started learning.
