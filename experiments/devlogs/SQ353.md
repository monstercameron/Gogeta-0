# SQ353: loop-state stability, pass dynamics and CKA on the 200M looped models

**Status:** done (descriptive, not registered) · **Verdict:** a smooth finite-difference perturbation gain is contractive for the full-precision loop models (E22 dense loop: relative gain 0.45 -> 0.85 over k = 1..4; A2f 0.57 / 0.74), but for every ternary loop model the response to a small perturbation is dominated by quantiser flips (the gain at eps = 1e-3 is 8.6x the gain at eps = 1e-2; relative gain at eps 1e-2 about 1.2 -> 0.9 in E27, 1.6 -> 1.1 in A2s, vs 0.45 -> 0.85 in the dense loop): ternary loops transmit perturbations about 2-3x more than fp loops and show a noise floor, not a smooth linear response · **Links:** script `experiments/checks/sq353_loop_stability.py`, results `experiments/checks/results/sq353.json` (per-model rows and group means)

## Method
Inference only, fp32 CPU, 8 fixed sequences x 256 tokens (concatenated clean80 val docs), default loops, every 200M-token checkpoint found on the fleet pulls: E22 (010), E27 (111), A1 arms, A2s, A2f, A3x, A3y, and E24 (unlooped GDN hybrid, CKA only); 55 models, one A1e checkpoint (seed 0) was unreadable (partial pull) and is skipped.
(1) Gain: before pass k's first core block, h gets random noise of norm eps x ||h|| per token (eps = 1e-3 and 1e-2); gain_k = ||change at the coda input|| / ||perturbation|| averaged over tokens; gain_rel = gain x mean||h|| / mean||coda input|| (scale-free; 1 = neutral, < 1 contractive). (2) cosine and relative step between consecutive pass states. (3) Linear centred CKA between pass outputs (and, for E24, between the 4 depth-matched block outputs at blocks 3, 6, 10, 13).

## Reading and caveats
- The small-eps (1e-3) gain in ternary models is an artefact of discontinuity: per-token int8 absmax quantisation and ternary weight rounding turn an infinitesimal perturbation into a few discrete flips whose effect does not shrink with eps; the 1e-2 numbers are the more usable measure. Even there ternary models amplify (relative gain 0.8-1.6) where fp loops contract (0.45-0.85); this is consistent with, but does not show, "ternary noise amplified across passes" as the cause of the fusion penalty (no intervention).
- A2s vs A2f: the ternary assembled model has about 2.8x (pass 1) / 1.5x (pass 2) the relative gain of its fp twin at eps 1e-2, with slightly higher cosine between passes (0.92 vs 0.90), nearly the same CKA (0.93 vs 0.95): pass outputs are very similar in representation (CKA >= 0.93) in every loop model, and the loop converges toward a near-fixed point after the first pass (cos 0.98 -> 0.998 in 4-pass models).
- E24, with block outputs of 4 depth-matched layers, has much lower CKA between layers (0.77 adjacent, 0.43 first-last) than any looped model between passes (0.92-0.995 and 0.92-0.97): loop passes are far more redundant than distinct layers, as expected from weight sharing.
- n = 2-8 per row, one 2k-token sample, no CIs; A2 (and A3) models have loops = 2.
