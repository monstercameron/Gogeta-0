# SQ99: out-of-corpus check

**Question:** does E1's advantage over E0 hold on Python the corpus can't contain? (outside review 19:07, idea I4)

**Prediction** (registered v0.4.54): out/in bits/char > 1.5× for both models; E1 still beats E0 out of corpus, by less.
**Criterion:** "transfers" if the gap is < 0 with its 95% paired BCa CI excluding 0.

## Results (`experiments/checks/results/sq_99.json`)
| | Out of corpus (330 files) | In-corpus clean val (1,340 docs, token-matched) |
|---|---|---|
| E1 vs E0 gap | **+0.42%** (CI +0.06..+0.78) | **−3.44%** (CI −3.82..−2.88) |
| Out/in bits/char ratio | E0 6.26×, E1 6.51× | — |

**Verdict:** DOES NOT TRANSFER. Ledger: C192 REFUTED (exploratory); a limitation on C5.

## Caveats
- Single-seed v0.3.0 checkpoints, untuned LR.
- E0 may be handicapped by its init (SQ200), which would *inflate* E1's in-corpus advantage, consistent with this result.
- Out-of-corpus is confounded with format and doc length.
- CPU fp32 with a reference GDN.

## Robustness (v0.4.65; quick review 19:25)
The per-doc CI ignores package clustering. Re-analysed on the saved per-doc NLL:
- by-source cluster bootstrap 95% CI −0.13% to +1.03% (includes 0);
- leave-one-source-out +0.26% to +0.56%, never flipping sign;
- E1 better on 14 of 31 sources.

**Read the result as: no evidence that E1's in-corpus advantage carries out of corpus.** Not as "E1 is worse".

## Length re-analysis (v0.4.66; outside review 20:07): the reading changes
| Out-of-corpus docs | n | Gap E1 vs E0 | Package-clustered 95% CI |
|---|---|---|---|
| 0–300 tokens | 29 | −3.86% | −4.94 .. −2.60 |
| 300–600 | 52 | −2.39% | −3.39 .. −1.32 |
| 600–1,200 | 96 | −0.56% | −1.13 .. +0.11 |
| > 1,200 | 153 | **+1.09%** | +0.48 .. +1.74 |

On short out-of-corpus files E1's advantage is the same size as in corpus (−3.44%, where docs average about 300 tokens). The pooled null comes from long files. **It's a length/long-context effect, not (only) a corpus effect** (C193). Equal-source weighting changes little: +0.31% vs +0.42% document-weighted, with the median source at +0.04%. Next: SQ214 (per-position bins + window sweep) and SQ218 (frozen test split).
