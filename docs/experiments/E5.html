Experiment E5 · Power Up on Demand

Adaptive loops per token

Charging

The question: Can a learned halting signal spend more loops on hard tokens and fewer on easy ones, at equal quality?

What it will test, in plain English

Let the model decide how hard to think, word by word. Easy tokens (a closing bracket) might need 1 pass through the loop; hard ones (the tricky line of an algorithm) might need 6. A small "am I done?" signal would decide when to stop.

If it works, you'd get the quality of many loops at the cost of few, on average.

Prediction (written before the run)

Not written yet. It must be written before the run starts.

Status

Not run yet. It needs a loop that actually improves with more passes first; E2 showed ours doesn't yet.
