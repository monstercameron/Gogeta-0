SCOUTER · POWER LEVEL

How to read the shapes

Nothing here is decoration. Each shape's size is a number from the code, and the legend says which.

Full attention: a triangular wedge

Every token looks at every earlier token: n²/2 scores. Its footprint's side is proportional to the context, so the area grows with the square. Slide the context to 32k and watch it balloon.

Sliding window: a thin diagonal band

Each token looks back only w = 256 tokens. The band has a fixed width and only gets longer: cost grows linearly.

Gated DeltaNet: a fixed cube

A small memory (heads × head_dim × head_dim) rewritten token by token. Tokens stream in, but the cube never grows with context.

MLP: a hexagonal bicone

Narrow, then wide, then narrow again: d → hidden → d. Height = its parameters. It works on one token at a time, with no look-back.

Plinth under each mixer: its weights

Height = parameters of the attention or DeltaNet layer. Scale: 1M params = 1.0 unit.

The Time Chamber: the looped core

One set of blocks stored once on a glowing ring, labelled × r. The loops slider unrolls it into a helix of translucent ghost copies: same weights, extra compute, so depth grows and parameters don't.

Re-inject disc

At the start of every loop the original input e is mixed back in (2d → d). The violet dashed beam carries it from the embedding.

Speckles: ternary weights

A −1 / 0 / +1 texture marks BitLinear layers (about 1.58 bits per weight). Embeddings and norms stay full precision, so they have no speckles.

Gold ki particles: data flow

Tokens rise through the prelude, orbit the core r times, then leave through the coda. Orange particles feed each memory cube.

    Numbers come from data/architectures.json, exported from the real model code by tools/viz/export_arch.py. Snapshot: …. FLOPs are per training token at sequence length 1024. Memory assumes bf16 (2 bytes per value); ternary models are shown 2-bit packed.
