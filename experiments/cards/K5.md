# K5: state tracking (running parity), single pass vs looped

## Question and prediction
- **Question:** are linear-time mixers weak at state tracking, and does looping a block add the missing depth?
- **Prediction (committed before running):** `experiments/checks/PREDICTIONS.md`, section "K5", commit `f1b4ebd`. (i) < 75%; (ii) better than (i) by an uncertain amount; (iii) ≈ (ii); (iv) < 75%.
- **Pass criteria:** "linear mixers weak" is supported if (i) < 90%. "Looping adds depth" is VERIFIED if (ii) ≥ (i) + 10 points and REFUTED if (ii) < (i) + 3 points. (ii) vs (iii) is reported only.

## Runs
Running XOR over 64 random bits (vocab 2), with loss on all positions. d=128, 2 heads, MLP 256. 3000 steps, batch 128, AdamW lr 1e-3, warm-up 100, cosine. Accuracy on positions 32–63 of 20 held-out batches of 128 (generator seed 10000). Seed 0 only (the design specifies no seed count).

| model | acc pos 32–63 | final train loss | train s |
|---|---|---|---|
| (i) 1 GDN block, 1 pass | 81.52% | 0.1436 | 34.6 |
| (ii) same GDN block looped ×4 (core, bptt 4) | 96.96% | 0.0224 | 86.3 |
| (iii) 4 unshared GDN blocks | 99.82% | 0.0019 | 73.8 |
| (iv) 1 attention block | 50.16% | 0.6375 | 15.3 |

## Results
- "Linear-time mixers are weak at state tracking": **SUPPORTED** ((i) 81.5% < 90%).
- **C18** "looping adds that depth": **VERIFIED** ((ii) 97.0% ≥ 81.5% + 10).
- Loop vs depth (reported): (ii) 97.0% vs (iii) 99.8%, a difference of −2.9 points.

## How to reuse this
- `parity_batch` + `evaluate` + `common.train_steps` are the template for any state-tracking A/B (new mixers, loop schedules, eigenvalue ranges). SQ6 (`experiments/checks/sq_06_rotation_parity.py`) reuses it with 2 seeds and a T=128 length-generalisation eval.

## Caveats
- **Single seed, and (i) is not robust.** SQ6 reran (i) with an identical config (same init, data and eval streams). It got 73.3% on seed 0 (vs 81.5% here) and 50.1% on seed 1. The gap comes from training-time GPU nondeterminism amplified by an unstable learning problem: the step-0 loss is identical. The (ii) result reproduced (97.2% / 98.7%). Treat 81.5% as one sample of a wide distribution. The C18 verdict holds on SQ6's 2-seed means ((b) 97.9% vs (a) 61.7%).
- (i) beat the prediction (< 75%) on this seed. GDN with β ∈ (0, 1) has no −1 eigenvalue, so part of its accuracy probably comes from shortcuts over finite T. It fails at length 128 (SQ6: about 50% on positions 64–127).
- (ii) and (iii) also fail to length-generalise (SQ6: (ii) 61% on positions 64–127).
