## 2. Critique

### 2a. Architecture (gogeta/model.py)

1. **The re-injection is ungated and accumulates.** `h = h + self.inject(cat[norm(h), norm(e)])` runs on every pass (model.py:302), and the state norm grows with r (C39, quoted). Nothing in the forward pass bounds it except the RMSNorm on the inputs (code-read).
2. **Init depends on loop count, so looped and unlooped arms can get different init scales.** `effective_depth()` counts r * len(core) (model.py:270-272), and `_init_weights` scales residual outputs by 1/sqrt(2 * effective_depth) (model.py:277). Two consequences (code-read):
   - Training samples r in U{1..7} but the init is set for the default r = 4.
   - Any comparison of a looped model with an unlooped one changes the init scale by construction. C6 (E2 vs E9) does not record this, and neither does SQ308's init story. If E9 is the 5-block layout, its init differs from E2's (spec until the staged config is checked).

### 2b. Method

3. **The F2 main effects inherit an init term nobody measured.** The dense cell E20 (cell 000) has no `init` key, so it uses the default "gogeta" init (staged-configs/e20_fact000.json, code-read). The two results in our own data point in opposite directions:
   - SQ200 (v0.4.88): on 6-block all-attention stacks, gogeta init costs about 3.5-3.8% (C199 PARTIAL).
   - SQ308 (v0.4.92): on the 14-block hybrid E32, gogeta init helps by about 7% versus flat.
   So the dense cell's init penalty at depth 14 is unknown, and README's "GDN alone is 7% better than dense" and "the full fusion is still 11% worse than dense" both carry it. The interaction I = y111 - y100 - y010 - y001 + 2*y000 cancels a shared all-attention penalty only if cells 000, 001 and 010 share one init scale. Cell 010 has loops, so its effective depth differs (spec).
4. **The headline lever is in-distribution only.** C197, C198 and C201 are all clean80 bpc on code-py. The one out-of-corpus test is REFUTED (C192), and the length reading (C193) is exploratory. Q14 is human-gated, so no claim about "better code" has a measurement behind it. The README sentence "Scale looks like the lever rather than loops" compares C197 (VERIFIED) with C6 (PARTIAL, one seed). That is an asymmetric status, and AGENTS 0 says wording must follow status.
5. **Tests are mixed inside one claim.** C197 compares E32 and E2 with paired tests (4 seeds), but E32 vs E1 uses a Welch test against E1's 7-seed mean (SQ283). Single-seed arms (E33, E34, E40-E48, E9) are compared with multi-seed arms without a stated rule.
6. **Paired-by-seed assumes shared batch order, and this is unchecked.** The paired CIs in C5, C198 and SQ241 treat the same seed as the same data order across arms. If model construction and batch sampling draw from one torch RNG, arms with different parameter counts see different batches at the same seed, so "paired" is not paired (spec: train.py was not read here).
7. **The loop verdict has three confounds that are still open.** (a) bptt_loops = 4 truncates the gradient for loops 1..r-4; SQ19 is NOT-READY. (b) E2 was trained at the CLI-overridden LR; the K7 sweep covered only E10 and E1, and Q10 (E2 at LR_E1) is queued, not run. (c) E2 vs E9 is one seed each.
8. **Verdict asymmetry, carried forward.** The previous review's I3 (one TOST rule across C5, C198, SQ282 W1 and C199) became SQ322. Until SQ322 runs, "no difference detected" is used for C5 and "lever = unique params" for C197 under different rules.

## 3. Alternative ideas (all speculation, spec)

**A. Init-matched factorial sensitivity.**
- Hypothesis: the F2 main effects (GDN vs dense, full fusion vs dense) move by more than 1% when cells 000, 100 and 111 are rerun at flat init.
- Cheapest test: 9 runs at 20M (3 cells x 3 seeds, the registered per-cell LRs, flat init). About 15-25 GPU-min (estimate: 0.6 min per run from v0.4.98, plus compile). Register it as a sensitivity first, with a note that it is post hoc.
- Changes plans: a move above 1% restates C201's main effects. An I that moves beyond its CI downgrades C201 to PARTIAL.
- Novelty: SQ200 (E0 only) and SQ308 (E32 only) test init, but not the registered factorial cells. Not queued.

**B. Causal context truncation at eval.**
- Hypothesis: E1 loses less than E10 when the visible prefix is cut from 512 to 256 tokens (its SWA window), because the GDN state carries information beyond the window.
- Cheapest test: on the existing 7+7 d = 384 checkpoints, cut the prefix to the last k in {64, 256, 512} tokens and measure clean80 loss. Inference only, about 5 GPU-min (estimate).
- Changes plans: a slope gap above 1% supports the state being used at long range (C18, C43). Coincident curves mean E1's edge is local, and C193's long-context reading becomes file type.
- Novelty: SQ203 (distance-to-last-occurrence bins) and SQ320 (position bins) are observational. Truncation is an intervention on context, and it is not in side-quests.

**C. LR-column robustness of the factorial interaction.**
- Hypothesis: I changes sign or size across the shared LR columns of the G3/F0 grid, not only at the per-cell best LR.
- Cheapest test: recompute I at each shared LR column from committed score files. CPU, under 10 min (estimate). Check first whether F0 results were recorded.
- Changes plans: a sign flip means "synergy" is conditional on LR selection, and C201 gets that limitation.
- Novelty: SQ263 tests the factorial at 200M, not the 20M grid. No 20M LR-column analysis is queued.

**D. Data-order pairing check.**
- Hypothesis: arms at the same seed see different training batches, so the "paired" CIs are partly unpaired.
- Cheapest test: hash the first 5 training batches of E1, E10 and E32 at seed 0, and read the sampler code. Under 5 CPU-min.
- Changes plans: if the batches differ, every paired CI needs a fixed-data-order rerun. If they match, one sentence goes into C5 and C198 limitations.
- Novelty: not in side-quests or the queue. It is a check on an assumption, which AGENTS 0 requires.

**E. Eval-time injection gain on the E2 checkpoint.**
- Hypothesis: scaling the re-injection term by a in {0, 0.25, 0.5, 1} at r = 4, 8, 12 lowers loss at r > 4 without hurting r = 4, which would make the un-gated inject the failure mode (C39, C7).
- Cheapest test: inference on the existing E2 checkpoint, about 3 GPU-min (estimate). It is off-distribution for an untrained gain, so the result is a diagnostic, not a fix.
- Changes plans: if L(12) improves at a < 1, SQ15 (contractive injection) moves up and the loop family gets a clearer target.
- Novelty: SQ14 rescales h and SQ15 changes the injection's parametrisation. An eval-time gain sweep on the existing term is not listed.

**F. Continuous overlap regression.**
- Hypothesis: the E1-minus-E10 per-doc gap has a nonzero slope in continuous 13-gram overlap with train, so the clean80 threshold choice matters.
- Cheapest test: regress the per-doc gap on overlap from the existing clean80 dumps, with package-clustered SEs. CPU, minutes.
- Changes plans: a clear slope makes SQ323 (discrete thresholds) the primary check.
- Novelty: weak. Adjacent to SQ323 and SQ190. Listed last because the increment is small.
