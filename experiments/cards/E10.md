# E10: Reference control (HF Llama at E0's size)

## Question and prediction
- **Question:** is our own dense baseline (E0) a fair yardstick? An unmodified Hugging Face `LlamaForCausalLM` at exactly E0's shapes, LR-tuned and run on 3 seeds, becomes the control.
- **Prediction (committed before running):** registry `experiments/experiments.json` → E10.prediction, plus the K7 and "Replication protocol" sections of `experiments/checks/PREDICTIONS.md`. Commit: the "registered" version that adds this card.
- **Pass criteria:** `PREDICTIONS.md`, "Replication protocol":
  - C5 (E1 beats E10) needs a gap > 2 × the pooled seed sd **and** max(E1) < min(E10).
  - E0 parity needs E0 within mean(E10) ± max(3 sd, 0.5%).

## How to run it
- **Config:** `configs/e10_llama_ref.json` (`"arch": "hf_llama"`).
  - Shapes: hidden 384, 6 layers, 6 heads × 64, SwiGLU 1024, tied 8k embeddings, RoPE θ 10000, RMSNorm eps 1e-6, HF init.
  - Training recipe identical to E0. lr 3e-3 is only the default: the real runs pass `--lr`.
- **Launch:** only through the campaigns (they need the launcher's `--lr` pass-through):
  - K7 (4 LRs × 20M tokens): `bash tools/launch_campaign.sh experiments/launch/campaigns/phase2a-k7-lr.campaign`
  - Replication: `python experiments/checks/k7_lr_sweep.py --write-campaign`, then `bash tools/launch_campaign.sh experiments/launch/campaigns/phase2b-replication.campaign`
  - Single run by hand: `bash experiments/launch/E10.sh --seed N --lr X [--dry-run]`
- **Code version:** the "registered" version after v0.3.5, where `train.py` gained `arch` and `--lr`.
- **Compute:** ~23 min per 200M-token run, estimated (assumed like E0, ~210k tok/s steady; not measured yet). A 40-step compiled bench ran: 85k tok/s overall incl. compile, peak 4.39 GB.

## How to reuse this
- **THE control** for every comparison once it lands: report "vs E10 (mean of 3 seeds, tuned LR)", not vs E0.
- Its seed sd is the noise estimate for single-seed comparisons of similar models.
- `"arch": "hf_llama"` in a config runs any HF-standard Llama variant through the same loop (for example, a larger control).
- Don't reuse it as a FusionDance building block: it's a different code path (HF modules).

## Caveats
- The LR is tuned at a 20M-token horizon and used at 200M (see the K7 caveats).
- Its init (std 0.02, no residual-output scaling) and RoPE layout differ from E0 on purpose: it's an outside reference, not a re-implementation.
- Throughput isn't measured yet.
