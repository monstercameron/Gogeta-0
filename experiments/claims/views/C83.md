- Affects GRPO rewards too (C83) (source: experiments/claims.md:L185) [event 2, v0.4.58]
- Network: with network='off' (default) the sandbox silently runs WITHOUT isolation when 'unshare -rn' is unusable (only 'require_off' raises; check result network_isolated). Fork bombs: RLIMIT_NPROC is set only when running as root (child = nobody); as a normal user they are cut off only by the wall-clock kill of the process group [event 4, v0.4.59]
- Fork-bomb resistance is unverified: no RLIMIT_NPROC for normal-user runs and no fork-bomb probe in post_training/test_rewards.py (tracked by SQ61's fail-closed gates) [event 5, v0.4.95]

- Update (v0.5.16): the v0.5.7 'reward forgery possible' limitation is resolved for the probed routes. After SQ373 every case in experiments/checks/reward_forgery_probe.py scores 0/1 (after-fix section of results/reward_forgery_probe_2026-11-23.txt), and 11 forgery cases are unit tests in post_training/test_rewards.py.
