Charging

The question: Linear mixers + loops + ternary together: do they stack, or does the fusion fail? Success here is v1.0.0.

What it will test, in plain English

The full fusion: all three ideas together in one model. Cheap memory layers instead of most attention (E1), a looped core (E2), and ternary −1/0/+1 weights (E3).

The bet is that each idea covers another's weakness: loops add thinking depth that the cheap layers lack, and ternary weights could make the extra loop passes cheap (only with real ternary kernels: ours are simulated and slower, check K2). If it works, that's version 1.0.0 of the project.
