## What it will test, in plain English

> **Teach the loop to fix its own mistakes.** Inspired by how AI coding agents work (write code, critique it, fix it, repeat), but built *inside* the model: every pass through the loop gets scored, passes that make things worse get penalised, and a small "critic" learns to predict how wrong the current answer is.
>
> [E2](E2.html) showed exactly the problem this targets: our looped model gets **worse** when it loops more than it was trained to. A loop that's rewarded for improving on every pass should keep getting better, or at least stop getting worse.
