The model, in 3D

Every shape is sized by a real number taken from the model code. Slide the context to watch full attention balloon while the memory cube stays put; slide the loops to see depth appear without new weights.

Design concept: numbers are estimates from notes/analysis-coarse-to-fine.md, not a trained model. This is the planned Byte Quest (E12–E16). The global stack is E1's real block list, run on patches; the byte-level blocks are E1's blocks scaled down for illustration. Loops r are limited to 1–4 here, and Play mode is off (no checkpoint to trace).
