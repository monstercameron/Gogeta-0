## Log (oldest first)

### 2026-11-23 · Change
- `run_tests()` is now `_gate()` + `_run_tests_unchecked()`. `_gate()` calls `self_test(REPO_ROOT)` on the first call in a process, caches the report in `_GATE`, and raises `RuntimeError("sandbox self-test failed (refusing to execute generated code): [failing probes]")` on every call if `ok` is false.
- `self_test()` itself uses `_run_tests_unchecked` (it is the probe, so it cannot be gated by itself), and stores its report in `_GATE` when called for the real repo root, so `run_suite.py`'s own earlier call satisfies the gate and the self-test is not run twice. `run_suite.py` is untouched.
- `gogeta_utils._exec_metrics` imports `run_tests` from `evals.sandbox`, so it is gated with no edit to `gogeta_utils.py`.
