# SQ351: length extrapolation of the 200M F2 cells 000 (dense RoPE attention) and 100 (GDN hybrid)

**Status:** done (descriptive, not registered) · **Verdict:** past the 1,024 training length the dense cell's per-token loss rises sharply (+160% in nats/token from the 512-1024 bin to the 1024-2048 bin on out-of-corpus code), while the GDN hybrid's falls (-10%); in the last bin GDN is 61% lower than dense. First non-analytic evidence for the efficiency pillar's length claim, with caveats below · **Links:** script `experiments/checks/sq351_length_extrap.py`, results `experiments/checks/results/sq351.json`

## Method
Cells 000 and 100, best LR (3e-3), seeds 0-2, fp32 CPU, GDN via the chunkwise torch kernel (matches GPU to 0.01%, SQ339 devlog). Each doc is scored in one window of up to 2,048 tokens (BOS + first 2,047 tokens); the RoPE cos/sin buffers of the model's shared `Rotary` module are overwritten with 2,048-position tables at eval time (gogeta/ untouched). Per-position NLL (nats/token) averaged by target position bin (0,512], (512,1024], (1024,2048]; the same docs for every cell and seed.
Doc sets: **A** = the clean80 val docs with > 1,200 tokens, as specified: only **3** exist (val docs: median 221 tokens, max 1,674; 4,469 tokens, 1,397 of them beyond 1,024) so A is anecdotal. **B** = the 153 SQ99 out-of-corpus local library files with > 1,200 tokens (K9-scanner overlap < 20% with train; paths and sha256 verified against `sq_99.json`; 269,305 tokens, 112,633 beyond 1,024). B is a distribution shift (raw library code: absolute NLL ~3-4 nats), so read the shape over position, not levels.
Control: the first 1,023 targets scored in a 1,024 window equal the 2,048-window values (max per-token |diff| 1.6e-5 nats, 0 for most), so RoPE extension changed nothing inside the trained range.

## Reading and caveats
- Inside the training length the hybrid is not better (equal in the first bin, ~13% worse in 512-1024 on both sets), outside it the dense attention model degrades while the hybrid keeps improving with context: the crossover is at about the training length. The ~13% deficit in 512-1024 is not explained here.
- Dense degradation here is for unmodified RoPE with positions never seen in training (no scaling or YaRN); the hybrid's last layer is full attention too, so part of its robustness comes from the GDN/SWA layers limiting what the attention layer sees: the mechanism was not isolated.
- Set B is out-of-corpus and shifted; set A has 3 docs. Document-level CIs are not reported; the CIs above are over 3 seeds (df 2) on one fixed doc set. Descriptive, not registered.
