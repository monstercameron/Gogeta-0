# E11: Negative-eigenvalue Gated DeltaNet for language modelling

## Question and prediction
- **Question:** does allowing GDN's write strength β ∈ (0, 2) (negative eigenvalues of `I − β k kᵀ`) cost or help language modelling? It's a single change vs E1.
- **Prediction:** registry `experiments/experiments.json` → E11.prediction (written 2026-11-22 before any run, committed in the version that registers it). The criteria are "free / helps / hurts" vs E1 by `max(1%, 2× pooled seed std)`.
- **Why now:** SQ6 arm (e) solved running parity in one pass (100.0% at T=64, 99.99% at positions 64–127) where looping reached 97.9% / 61.2% (ledger C43). If it's also free for LM, it changes what FusionDance needs the loop for.

## How to run it
- Config: `configs/e11_negeig.json` (= E1 + `gdn_neg_eigval: true`; same params 14.24M and FLOPs as E1)
- Code: `gogeta/model.py` `GatedDeltaNet` passes raw β logits with `use_beta_sigmoid_in_kernel=True, allow_neg_eigval=True` when the flag is on (β = 2·sigmoid). The default path is unchanged. Tests: `tests/test_model.py` (causal; differs from default with identical weights, max logit diff 0.25).
- Launch: `bash experiments/launch/E11.sh --seed N` **at E1's tuned LR from K7** (pass the LR override the campaign uses), seeds 0, 1, 2.
- Compute (estimated): ~39 min per seed (as E1), ~2 h for 3 seeds.
