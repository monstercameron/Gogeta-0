# SQ392: positional control for the long-context result (linear RoPE interpolation on the dense arm)

**Status:** done (registered in PREDICTIONS.md section SQ392 and its protocol clarification) · **Verdict:** the registered prediction (the hybrid's advantage past 1,024 tokens shrinks from -60.7% to about -30%, range -45% to -10%) is NOT met: zero-shot linear position interpolation (positions / 2) makes the dense cell worse everywhere, including past 1,024 (+15.0% nats/token, 95% CI +2.1 to +28.0), so the hybrid's advantage in 1024-2048 grows to -78.3% (CI -86.0 to -70.5). By the registered rule ("still beyond -50% -> the long-context result stands as stated") it stands, with the caveat that interpolation without fine-tuning is a weak positional control · **Links:** script `experiments/checks/sq392_rope_interpolation.py`, results `experiments/checks/results/sq392.json`

## Method
SQ351's dense cell 000 (best LR 3e-3, seeds 0-2), window 2,048, both arms built with the RoPE table for 2,048 positions: raw positions 0-2047 (baseline) and positions / 2 before the cos/sin lookup (scale 1/2 for 2048 / 1024). Same two doc sets (A: 3 clean80 docs > 1,200 tokens; B: 153 SQ99 out-of-corpus files > 1,200 tokens), same per-position-bin NLL; the hybrid arm (cell 100) is read unchanged from `sq351.json`. The raw dense arm reproduces SQ351's dense numbers exactly (max abs difference 0.0 nats/token). Advantage = 100 x (exp(nats_hybrid - nats_dense) - 1), paired by seed, 95% t-CI (df 2).

Set A (3 clean80 docs): the same picture (interpolation +61%, +80%, +40% nats; hybrid vs dense in 1024-2048 -29.1% raw, -60.9% interpolated).

## Reading and caveats
- Unfine-tuned position interpolation changes the angles the dense model saw in training for the in-range positions too, so it damages 0-1024 as well (+28% and +53%): the control tests "does halving positions rescue the dense arm" and the answer is no; it does not test the best possible positional treatment of a dense model (NTK-aware scaling, YaRN, interpolation plus a short fine-tune, or ALiBi-style extrapolation would). The honest restatement: the hybrid's -60.7% is versus unscaled RoPE; versus zero-shot linear interpolation it is larger; versus a properly extended dense model it is untested.
- The raw -60.7% did contain the dense arm's raw degradation (+31.5% from bin 2 to bin 3 on B), and the prediction assumed interpolation removes half of it; instead it adds 15% on top of the raw bin-3 level.
- n = 3 seeds (df 2), one fixed doc set of 153 files (set A has 3 docs); descriptive beyond the registered rule.
