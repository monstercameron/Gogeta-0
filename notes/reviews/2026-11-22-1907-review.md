## 2. Critique

1. **The clean set is one arbitrary cut.** The primary metric removes only docs with at least 80% 13-gram overlap. The 1,159 docs between 50% and 80% (2,826 minus 1,667, K9.json) stay "clean", and K9 notes that exact 13-grams miss paraphrase. The memorisation gap therefore contrasts a memorisable band with a partly memorisable one. Report bpc as a function of overlap (a sweep at 50/65/80/95%). Freeze the clean list against the union of all train sets before v2 exists, so the v1/v2 bridge scores the same docs.

2. **Dedup changes the regime as well as the data.** A3 §0 requires A1 to report the epoch count if v2 has under 200M unique tokens, but nothing analyses it. Dedup removes repeats and adds epochs at once. A3 itself says memorisation is architecture-dependent, so the bridge can show that a ranking moved but cannot say why. No arm varies repetition alone.

3. **Cost is FLOPs everywhere except the caveats.** README line 91 still says E1 wins "at slightly less compute", and the factorial matches on block applications. The question a practitioner asks is loss at equal GPU-minutes, and no registered arm answers it. At 20M, K7 measured E10 at 177k to 186k tok/s and E1 at 108k to 145k (design-rigor §2).

4. **Ternary is not one ingredient.** BitLinear quantises weights (absmean ternary) and activations (8-bit, per row) in the same forward pass (model.py:73-78). The factorial's ternary factor therefore bundles two changes, against AGENTS §5's one-ingredient rule. Add a full-precision-weight, int8-activation arm so the two can be split.

5. **The loop, the thesis's central ingredient, is the least replicated.** E2 and E9 stay single-seed unless SQ127 runs, and E2 is in no staged HPO step. E9 is the only unlooped control queued, and it has 0.41x E2's FLOPs, so it matches parameters, not compute. The FLOP-matched arms E32 to E34 are staged only. Queue them, and E2 seeds 1 and 2, before the factorial starts. Otherwise the loop verdict rests on one untuned run.

6. **n = 3 cannot verify anything.** The exact sign-flip test cannot go below p = 0.25 at n = 3 (18:36 statistician review), and the policy needs a CI that excludes 0. Phase 2b's C5 can reach PARTIAL at best. The factorial pilot (F1, seeds 1 and 2) gives about 5 df for sigma, roughly ±30%, and N = 46 scales with sigma squared, so N could be about 1.7x off. The pilot's decision rule has no written threshold. The E1 decomposition's reading rule (design-rigor §4) also assumes sd 0.4%, which is C93 UNVERIFIED. Write the thresholds, and budget n = 5 for H1 and H2 (two more seeds each of E10 and E1 at 200M, about 2.1 GPU-h).

7. **The loop is evaluated at r = 4, a value chosen after looking.** r = 4 was E2's best depth on the same data (C7), and the factorial's looped cells evaluate at r = 4. Pre-register the full in-distribution curve (L(r) for r = 1 to 7) and report the loop main effect as a function of r.

8. **The length test cannot run on the current code.** Rotary is built for max_seq_len = 1024 (model.py:227), and forward slices `cos[:, :, :T]` (model.py:98). SQ52 (train at 512, evaluate to 2048) would fail on a shape mismatch at T = 2048. It needs a patch and a test before it is marked ready.

9. **Nothing in the designs I read tests transfer beyond the corpus.** A2 and A3 score in-corpus held-out docs only. K9 measures memorisation inside the corpus, not generalisation beyond it, and pass@1 floors at this size (C102). The headline could pass every planned check and still be an in-corpus effect. [spec]

## 3. Alternative ideas

The 18:07 ideas A to F are accepted or queued, so these six are new. Each is sized for the 13M scale.

**I1. Equal-time efficiency.** Hypothesis [spec]: at equal measured GPU-minutes, the dense model matches or beats E1. Test: E10 seed 0 at lr 3e-3 for about 28M tokens (1.4x the tokens, about the same wall-clock as E1's 20M run at K7 rates), roughly 3 GPU-min. Compare with E1's K7 result at 20M (0.9925, packed protocol). Changes plans: E10 beating 0.9925 by more than 0.008 (2 sd) withdraws the efficiency claim, and A3 should lead with time, not FLOPs. Novelty: A3 asks for loss vs GPU-minutes but registers no run for it. SQ125 re-measures speed only.

**I2. Does the hybrid gap survive width?** Hypothesis [spec]: the E1-vs-dense gap shrinks with width, as K4 found for ternary. Test: d = 128, 256, 384, each attention-only and E1 layout, seeds 0 and 1, 20M tokens, LRs {3e-3, 6e-3}; about 30 to 35 GPU-min. Changes plans: a gap that reaches zero by d = 384 makes the 3.6% a small-scale effect, and E4 needs another case. A gap that grows makes the hybrid a scale-dependent win. Novelty: K4 covers ternary only. E34 and SQ33 vary width or tokens for the loop and E9, not the mixer.

**I3. E8's premise without a KV cache.** Hypothesis [spec]: a 1-loop draft agrees with the 4-loop verifier often enough to speed up decoding. Test: E2 checkpoint, 256 docs from the clean set, one teacher-forced forward each at r = 1, 2 and 4. Report per-token argmax agreement and the mean run of agreeing tokens in blocks of 4. No decode path is needed; about 2 GPU-min. Changes plans: agreement(r=2, r=4) below 70% drops shallow-loop drafting for E2 and deprioritises E8. Above 85% moves SQ53 up. Teacher-forced agreement approximates greedy acceptance but is not a bound [spec]. Novelty: E8 is blocked on SQ53, and SQ92 measures per-token loss, not draft agreement.

**I4. Out-of-corpus check on disk, no download.** Hypothesis [spec]: the E1 advantage holds on Python the corpus does not contain. Test: run K9's scanner over local Python files (stdlib, installed packages), keep docs with under 20% 13-gram overlap with train, and score E0 and E1 (plus E10 once Q7 finishes) doc-level. Inference only, about 3 min. Changes plans: a gap that vanishes or flips beyond 2 sd makes the headline in-corpus, and A3's decomposition moves up. A preserved gap supports generalisation. Compare gaps only within this set, since domains differ, and the scanner must confirm the overlap is low. Novelty: K9 is within-corpus. SQ62 and SQ69 need downloads, and SQ69 is human-gated.

**I5. Repetition as an axis.** Hypothesis [spec]: the hybrid-vs-attention gap depends on how often training text repeats. Test: E0 and E1 trained on 20M unique tokens for 1 epoch, and on 5M unique tokens for 4 epochs, at equal steps, two seeds each. Score clean-val bpc and the memorisation gap; about 20 GPU-min. Changes plans: a gap at 4 epochs more than double the 1-epoch gap means the v1 headline is repetition-inflated, and the v2 bridge becomes the decisive test. Novelty: the A3 bridge changes the dataset at one budget. Repetition is never varied alone.

**I6. Remove the global layer.** Hypothesis [spec]: a hybrid with no full attention matches E1 at 1k context. Test: E1 with its coda attention replaced by SWA, 20M tokens, two seeds, against E1 at the same LR; about 5 GPU-min. Changes plans: within 2 sd, "one full-attention layer outside the loop" is untested at 1k context and should be called a design choice, not a result. Worse by more than 2 sd, the global layer is load-bearing and E4 keeps it. Novelty: E41 and E48 both keep the attention coda, so no arm removes it.

## 4. Experiment to run next

Run I4, the out-of-corpus check. It needs no training, reuses the E0 and E1 checkpoints and K9's scanner, takes minutes, and tests what the rigor program does not: whether the headline survives data it could not have memorised. If the gap vanishes, the decomposition and the cost story should be re-scoped before more GPU time is spent. The prediction must be registered before the run (AGENTS §6). My prediction [spec]: the sign holds and the magnitude shrinks.
