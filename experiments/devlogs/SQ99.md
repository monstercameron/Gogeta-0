K9 showed 41.7% of val docs are near-duplicates of train (>= 80% of 13-grams), so every planned in-corpus test is optimistic and may favour whichever model memorises better. SQ99 scores E0 and E1 (v0.3.0 seed-0 checkpoints, untuned LR, so exploratory) on local Python files the corpus cannot contain (CPython stdlib plus the `~/.venvs/gogeta*` site-packages, no downloads, per-source caps, K9's 13-gram scanner keeps docs with < 20% overlap with train.bin) and on a token-matched sample of K9-clean val docs (< 80% overlap), both through the same fp32 CPU path (GDN via a plain-PyTorch gated-delta-rule reference, as `experiments/viz/export_trace.py`). The result stores paths and sha256 only, never file contents. PREDICTION and CRITERION are constants at the top of the script, to be committed before the real run.
