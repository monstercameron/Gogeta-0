## 2. Critique

Builds on the 20:40 review; its items 1-13 are not repeated.

1. **SQ214 cannot test the > 1,200 bin.** Both arms see at most 1,024 tokens per scored window, and longer docs are chunked (SQ214 devlog, 20:50 caveat). C193's limitation (event 4) rests on the aggregate clean80 mean, not on the long-doc bin the claim is about. The position-binned scoring from SQ214's original design is still open (side-quests, SQ214 row: "partly done").
2. **"Beats 64" is not significant.** The brief and DEVLOG v0.4.73 count w64 as a W2 pass on magnitude; the paired test is t 2.91 < 3.18 at df 3 (SQ214 devlog). The wording should say "not significant at n=4".
3. **E1 vs E10 mixes mixer and init.** E0 and E10 differ by 3.7% at identical shapes, a pure init/implementation effect. E1 keeps E0's residual-output init (`gogeta/model.py:246-250`, std 0.02/sqrt(2·depth)); E10 uses flat 0.02 (SQ200 row). SQ200 swaps init only for E0 and E10, so the E1 arm is never tested. "Phase 2b is protected" because it uses E10 covers the baseline choice, not this.
4. **The Phase 2b verdict is at the noise floor.** With sd 0.0020 per arm and n = 3, the Welch SE of the E1-E10 difference is about 0.0016, so +0.0008 is about 0.5 SE (computed). Detecting 0.003 (0.3%) at 80% power needs about 7 seeds per arm (computed). The verdict should state the resolvable effect before it is written.
5. **"Tuned" LR may be within noise.** K7's margin between the chosen LR and its neighbours is not in the files I read. The SQ214 pooled seed sd (0.39% at 20M, E1 only) implies LR choices closer than that are not separable (computed).
6. **The SKU tolerance is unmeasured.** The +/-0.004 tolerance is provisional, and no same-SKU rerun floor exists. A 0.0020 delta is about one E10 seed sd at 200M (computed). The cross-SKU test cannot separate numerical drift from seed noise, which is why C195 is PARTIAL. See I1.
7. **Speed and $/token rest on one 20M run per SKU,** on 13.8M models that are overhead-bound (DEVLOG v0.4.71). The "cheapest per token" ranking covers rented SKUs only. The N1X "$0.02/hr" is assumed electricity and excludes capital.
8. **FLOPs do not describe SWA's cost.** `flops_per_token` counts SWA as `min(window, seq/2)` (`model.py:307`), but the kernel is a dense T x T masked SDPA (`model.py:124-141`), so w64 and w1024 cost the same wall-clock. SQ214 reports no per-arm time, so "compute-matched" holds only in the FLOP formula.
9. **Bookkeeping drift.** INDEX lists E10 as "planned, not run yet" while DEVLOG v0.4.70 reports three E10 seeds. SQ214 and SQ220 show no card (AGENTS §6). README line 47 still says E1 is queued. INDEX cites the frozen claims.md.
10. **Pre-registration and resume provenance.** The SQ214 devlog says the 2-to-4 seed amendment was written before launch, but its "20:50" stamp is approximate and the job started at 20:47:05. The claim rests on file or commit times, which should be checked. Separately, a resumed E1 s0 ran 20:53-21:01 on the N1X and was killed. The devlog does not say whether its partial run folder could collide with the completed E1 s0 (same config, same seed), or whether it was excluded from the 3-seed mean.

## 3. Alternative ideas

**I1. Same-SKU determinism floor** (adjacent to SQ220, not queued). [spec] Hypothesis: same-seed, same-SKU reruns of E10 and E1 at 20M tokens differ by at most about 1e-4, so the cross-SKU deltas are numerics, not seed noise.
- Test: one rented 5090, E10 and E1 at 20M, seed 0 twice each, plus seed 1 once each. About 6 runs at ~30 s each, under $0.05. Destroy the box after the last run (AGENTS §0h).
- Changes plans: if same-SKU reruns differ by about 0.002, C195's transfer claim is noise-level, and the tolerance must be rebuilt from this floor.
- Novelty: SQ220 measured across SKUs only; SQ231 is throughput.

**I2. Delta-rule ablation: GDN vs a decay-only gated linear mixer.** [spec] Hypothesis: E1's gain comes from the decay gate, not the delta-rule overwrite.
- Test: swap the GDN kernel for fla's gated-linear kernel (if fla 0.6.0 ships it; not checked) in E1's three GDN slots. One ingredient, 20M tokens, 4 seeds, about 3 min on a 5090.
- Changes plans: if the decay-only mixer matches E1, the delta-rule story behind C16/C43 is not what E1 buys, and SQ51 (KDA) becomes the more relevant mixer question.
- Novelty: SQ2 changes beta's range, SQ8 the output gate, SQ51 decay granularity. None removes the delta update.

**I3. Membership gap: trained vs untrained docs from the same distribution, per architecture.** [spec] Hypothesis: E1's advantage is larger on documents it trained on than on unseen ones of the same distribution, and E10's is not.
- Test: score about 500 docs consumed in training and about 500 past the consumption point (about 60M of the ~262M-token subset is unseen at 200M, computed). Needs the stream order from `train.py` (not read). CPU or a short GPU job.
- Changes plans: a membership gap for E1 larger than E10's by about 1% would make the in-corpus headline partly memorisation, and C5's wording would change.
- Novelty: K9 scores val near-dups and SQ204 is an n-gram floor; neither compares architectures on trained vs untrained docs.

**I4. E1 under HF-Llama init** (the missing E1 arm of SQ200). [spec] Hypothesis: E1's gap to E10 shrinks or changes sign when E1 uses E10's init, as E0's did.
- Test: E1 with flat 0.02 init, 20M tokens, seeds 0-1, about 2 min on a 5090.
- Changes plans: if the gap moves by more than the E0 init effect (about 3.7%), the Phase 2b E1 arm should be re-run with E10 init before its verdict.
- Novelty: SQ200 changes init only for E0 and E10.

**I5. Length extrapolation for a GDN-only model.** [spec] Hypothesis: GDN has no positional encoding, so a GDN-only model trained at 1,024 keeps flat or falling per-position loss beyond 1,024, where models with attention do not.
- Test: train 6 GDN blocks at 20M tokens (about 30 s on a 5090) and score per-position loss to 4,096. The `Rotary` cap (`model.py:52`, `97-98`) applies only to attention blocks, so this model is not capped.
- Changes plans: if loss rises past 1,024, the constant-state pitch has no length evidence in this repo. If it falls, this is the only test that uses the linear-time property directly.
- Novelty: SQ52 tests NoPE in one attention layer; SQ214 caps at 1,024.

**I6. Power pilot before the Phase 2b verdict.** [spec] Hypothesis: at 20M tokens, 8 seeds each for E1 and E10 give sd below 0.3%, enough to size the 200M verdict.
- Test: 16 runs at 20M, about 30 s each on a 5090, under $0.10.
- Changes plans: if the 20M sd is above about 0.5%, the 200M verdict is underpowered at n = 3 and should be labelled exploratory until more seeds run.
- Novelty: SQ216 and SQ214 cover window arms and X1, not E1 vs E10.
