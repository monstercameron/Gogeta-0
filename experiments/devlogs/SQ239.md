# SQ239 (+ extensions): source-config, parseability and threshold splits of the A2/A3 headlines

**Status:** done (exploratory, never changes a claim status) · **Verdict:** no sign flips by source config, parseability or overlap threshold. Headline effects move monotonically with the threshold (stronger on the full val than at clean50): clean50 -> clean80 -> full: ternary cost +7.85 -> +9.65 -> +10.87%, loop cost +2.38 -> +3.08 -> +3.49%, assembly gain -15.28 -> -16.67 -> -17.93%. Two flags: the assembly gain differs by 3.4 points between source configs (algorithmic -14.4% vs synthetic -17.8% on clean80), and A3mx vs E20 changes by more than 30% at clean50 (+1.10% -> +0.53%, both CIs include 0) · **Links:** `experiments/checks/sq239_perdoc_rescore.py`, `sq239_analysis.py`, `sq239_parseability.py`; results `results/sq239.json`, `results/sq239_nll/*.npz` (per-doc NLL, token counts, position-bin NLL), `results/sq239_parseability.json`

## Method
CPU stand-in for `score_doclevel.py --store-nll` (no GPU): per-doc NLL of 30 checkpoints on ALL 4,000 code-py-v1 val docs (K8 protocol, window 1024, fp32; the clean80 numbers agree with the GPU scorer to about 0.01%): A2s, A2f, E20, E24 at the seeds found in 2-7, E27 seeds 2-4, A3mx seeds 5-7, best LR. Effects: paired-by-seed 100 x (bpc_a / bpc_b - 1) on the subset, mean and t-CI (df = n - 1). Subsets: full val (4,000), clean80 (2,333, K9 overlap < 0.8), clean50 (1,174), and each source config within clean80 and full. Note: the v2 val set is not local, so "full v2 val" is the full v1 val here (the models were trained on v2).
