## Triage
- Prompt-format sensitivity (raw prefix vs instruction-wrapped): rejected at 13M. Base models trained on raw Python files have never seen instruction wrappers, so the wrapped format is out of distribution by construction. Pass@1 at this scale sits at the ~2% floor (`notes/benchmark-suite.md`), so 100 tasks cannot resolve a 5-point shift. It belongs to the post-training stage (GRPO/SFT in `post_training/`), where instruction formats are trained, and to Q14 at final scale.
- Distractor sensitivity: kept as a likelihood version rather than pass@1, merged into SQ385 (position-resolved clean80). Insert unrelated in-repo code before a held-out target and measure the target tokens' NLL change for A2s, E24 and E20. That needs no generation and works at 13M. The pass@1 version waits for Q14 at final scale.
- Question (which workflow is the final model's primary target?): completing a file from a code prefix, as answered at 12:29, 13:24 and 15:39. Goal 6 is interactive left-to-right completion with self-speculative decoding. Instruction following is a post-training layer (`post_training/`, GRPO on the sandboxed reward harness) on top of the base model, not a pretraining target.
